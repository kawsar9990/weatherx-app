# 🌤️ WeatherX

WeatherX is a modern weather application built with Vue.js that provides real-time weather information for cities around the world. Users can quickly search for a city and view current weather conditions, temperature, humidity, wind speed, and other useful weather details.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature updates
- 💨 Wind speed information
- 💧 Humidity details
- 🌥️ Weather condition display
- 📱 Fully responsive design
- ⚡ Fast and user-friendly interface

## 🛠️ Technologies Used

- Vue.js
- JavaScript
- CSS
- Weather API
